# Frontend

React frontend for the Clinic Appointment Booking System.

## Tech Stack

- React
- Vite
- React Router
- React Bootstrap
- JavaScript

## Features

- Guest appointment booking
- Patient registration and login
- Patient dashboard
- Appointment management
- Doctor search
- Clinic overview
- Responsive user interface
- Admin dashboard

## Run the Project

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Frontend URL:

```txt
http://localhost:5173
```

## Environment Variables

Create a `.env` file in the Frontend project:

```env
VITE_API_BASE_URL=http://localhost:5048/api
```

## API Integration

The frontend communicates with the ASP.NET Core backend API.

Default API URL:

```txt
http://localhost:5048/api
```

Swagger documentation:

```txt
http://localhost:5048/doc
```

## Routing

The application uses React Router for navigation between:

- Guest booking pages
- Authentication pages
- Patient dashboard pages
- Admin dashboard pages
